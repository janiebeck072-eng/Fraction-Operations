📌 Reference desk

PEMDAS: Parentheses → Exponents → Multiplication / Division (left to right) → Addition / Subtraction (left to right).

Signs: Multiply or divide: same signs = positive; different signs = negative. To subtract, add the opposite.

Fraction rules: For multiplication, multiply numerators and denominators. For division, multiply by the reciprocal. For addition/subtraction, use a common denominator.

How to enter answers: Use -3/4, 5/2, or 2. Equivalent fractions are accepted. Complete each box before the next one appears.
